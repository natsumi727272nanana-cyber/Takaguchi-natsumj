# enu アカデミー アプリ

スマホ縦型で見る、新人教育アプリの試作版です。`index.html` と `content.js` を同じフォルダに置いて、ブラウザで開くと動きます。

## ページ
- enu の理念（いちばん上）
- ホーム：名前・入社何ヶ月目・合格数・今月の目標、チェック待ち、次に取り組む課題
- 新卒（2027年4月入社）：4月までに合格すること・予習すること・シャンプーレッスン日程・初日までに読むこと
- アシスタント：アシスタント業務（お店の仕事・施術のアシスト）
- スタイリスト：スタイリストになるために（カット・カウンセリング）
- 100万円：100万円に行くために（集客・再来・売上管理）
- ロードマップ、みんなの進み具合（幹部・オーナー）
- オーナーAIチャット、マイページ（入社日・目標デビュー日・今月の目標）
- 画面下のタブ：ホーム・新卒・アシスタント・スタイリスト・100万円（幹部・オーナーはスタッフも）。マイページはホームの名前のカード、AIチャットはホームの下から

## 中身の書き換え方
中身はすべて `content.js` にあります。アプリ本体（`index.html`）はさわらなくて大丈夫です。

- `philosophy` … 理念
- `groups` … 項目の並び。`page: "work"` はアシスタントのしごと、`"lesson"` はレッスン
- `lessons` … 1レッスンずつの中身（`type` で合格の決まりが変わります。ファイルの先頭に説明あり）
- `chatSources` … オーナーAIチャットが答えの根拠にするマニュアル
- `ownerQA` … AIが使えない場所でのキーワード回答

## 合格の決まり（開発資料 6章）
| type | 合格の流れ |
| --- | --- |
| chore | 雑務。やり方を見て覚えたら自分で「覚えた」 |
| quiz | アプリのテストで全問正解 |
| tech | ウィッグで5回練習 → 先輩の○×チェック（すべて○）→ 必要なら人頭 |
| theory | 先輩が口頭で質問し、すべて答えられたら合格 |
| shampoo | 採点表で80点以上＋★必須3項目が満点（5回目から合格判定） |
| roleplay | ロープレ3回。言葉・判断・カルテを確認 |
| read | 読んで覚える |

先輩のチェックは、幹部・オーナーが登録時に決めた4桁の暗証番号で記録します。

## 記録の保存
- **claude.ai で開いたとき（共有モード）**：全員の記録が共有されます。開いた人は Claude のアカウントで見分けます。
  - スタッフは、オーナーが共有メニューから**メールで「編集者」として招待**します（「リンクを知っている全員」の共有はオフにしておく）。
  - 幹部（監督）は、オーナーが「スタッフ」タブの「スタッフと役割」で決めます。
  - 合格のチェックは、幹部・オーナーが自分のスマホで記録します（スタッフ → 名前 → レッスン）。アシスタントは自分で合格をつけられません。
  - 保存先：`members/<id>`（本人の記録）、`roles/<id>`（役割・オーナーだけが書ける）、`checks/<幹部のid>/records`（合格チェック）
- **それ以外で開いたとき（ファイルを直接開くなど）**：その端末のブラウザに保存され、先輩のチェックは暗証番号で記録します。
- オーナーAIチャットは、claude.ai 上で開くとAIが答えます。それ以外の場所では、マニュアルから近い章を表示します。
