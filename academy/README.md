# enu アカデミー アプリ

スマホ縦型で見る、新人教育アプリの試作版です。`index.html` をブラウザで開くだけで動きます。

## 中身の書き換え方
`index.html` の上の方、「コンテンツ」と書かれた部分を編集します。

- `PHILOSOPHY` … トップページの enu の理念
- `PRE_ENTRY` … 入社前プログラム（電話・挨拶の確認テスト、予習動画）
- `TASK_GROUPS` … アシスタントのしごとの項目と順番
- `TASK_DETAIL` … 各項目の動画URL（`video`）・やり方（`steps`）・合格チェックポイント（`checks`）
- `ROADMAP` … 4月入社〜12月デビュー〜100万円までの道のり
- `OWNER_QA` … オーナーAIチャットの質問キーワードと答え

## いまの制限
- 名前と進み具合は、その端末のブラウザに保存されます。別のスマホとは共有されません。
- オーナーAIチャットはキーワードで答えるサンプルです。本物のAIにするにはサーバーとAPIキーが必要です。
